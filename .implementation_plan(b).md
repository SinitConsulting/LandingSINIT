# Plan de Implementación: Prueba de Color (Modo Oscuro)

Vamos a crear una maqueta paralela completa para probar la nueva paleta de colores oscuros sin alterar tu página principal actual (`/`).

## Resumen de Cambios Propuestos

1. **Creación de nueva página (`/prueba-color`)**:
   - Se creará el archivo `src/pages/prueba-color.astro`.
   - Esta página será accesible directamente en el navegador (ej. `localhost:4321/prueba-color`).

2. **Creación de Componentes Paralelos**:
   - Para tener un control preciso sobre la paleta de colores y contrastes según tus indicaciones, duplicaré los componentes clave (Hero, ProblemSection, Services, etc.) con el sufijo `Dark` (ej. `HeroDark.astro`).
   - Esto asegura que **no haya absolutamente ninguna modificación en tu código de producción actual**.

3. **Aplicación de la Paleta de Colores**:
   - **Fondo General**: Azul Marino Profundo (`bg-slate-900` o `#0F172A`).
   - **Tarjetas/Secciones**: Azul pizarra (`bg-slate-800` o `#1E293B`) con bordes finos de 1px en `#334155` (`border-slate-700`).
   - **Contenedor del Chatbot**: Tono más elevado (`#2D3748`).
   - **Textos Principales (H1/H2)**: Blanco humo (`text-slate-50` o `#F8FAFC`).
   - **Párrafos**: Gris pizarra claro (`text-slate-400` o `#94A3B8`).
   - **Botones/CTAs**: Fondo celeste actual, pero el texto pasará a ser `#0F172A` o `#111827` para un contraste táctil y profesional.
   - **Iconos**: Cambiarán de los tonos rojizos actuales a tonos menta/verde agua (`text-teal-400` o `#2DD4BF`) para destacar sobre los fondos oscuros.
