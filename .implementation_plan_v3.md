# Implementación de Fondo Animado Estilo Astro.build

Vamos a implementar un fondo global animado con tonos oscuros (azul profundo y detalles dorados) y transiciones fluidas, eliminando los colores sólidos de cada sección para que el efecto visual se aprecie en toda la página.

## Cambios Propuestos

### 1. `src/layouts/BaseLayout.astro`
- **[MODIFICAR]**: Añadiremos un contenedor `div` con posición `fixed` en el fondo (`-z-10`) que cubrirá toda la pantalla.
- **[MODIFICAR]**: Crearemos una animación CSS con `@keyframes` para mover y transicionar suavemente gradientes radiales (mesh gradient) en tonos azul oscuro y dorado oscuro.
- **[MODIFICAR]**: Estableceremos el color de fondo base del `body` en un tono muy oscuro o negro para dar soporte al gradiente.

### 2. Actualización de Secciones
Eliminaremos los fondos sólidos para que el gradiente animado sea visible. Aplicaremos un estilo *glassmorphism* (fondo semitransparente con desenfoque) si es necesario para mantener la legibilidad, o simplemente dejaremos el fondo transparente si el contraste es suficiente.

- **[MODIFICAR]** `src/components/Hero.astro`: Remover `bg-zinc-800`.
- **[MODIFICAR]** `src/components/ProblemSection.astro`: Remover `bg-[#0F172A]`.
- **[MODIFICAR]** `src/components/PositioningSection.astro`: Remover `bg-[#1E293B]`.
- **[MODIFICAR]** `src/components/ServicesGrid.astro`: Remover `bg-[#0F172A]`.
- **[MODIFICAR]** `src/components/ProcessSteps.astro`: Remover `bg-[#0F172A]`.
- **[MODIFICAR]** `src/components/TrustSection.astro`: Remover `bg-[#1E293B]`.
- **[MODIFICAR]** `src/components/Footer.astro`: Ajustar color para que combine (ej. fondo transparente o semitransparente).

## Detalles del Efecto
El efecto consistirá en gradientes radiales que se mueven lentamente, similar al sitio web oficial de Astro. Utilizaremos CSS puro para la animación, asegurando un excelente rendimiento.
