Este documento detalla el plan técnico y arquitectónico para construir la landing page de **SINIT Consulting**, cumpliendo con los requisitos de posicionamiento, stack tecnológico y flujo de leads.

## Proposed Changes

El proyecto se estructurará siguiendo la arquitectura propuesta de Astro y Netlify Functions.

### 1. Inicialización y Configuración

- Inicializar proyecto Astro con TypeScript (`npx create-astro@latest . --typescript strict`).
- Configurar integraciones: `@astrojs/netlify` (para las funciones SSR), `@astrojs/sitemap`.
- Configurar ESLint y Prettier.
- Crear `netlify.toml` para el despliegue automático y el redireccionamiento `/api/*` -> `/.netlify/functions/*`.
- Configurar `.env.example` con la variable `N8N_WEBHOOK_URL`.

### 2. Capa Backend (Netlify Functions)

#### [NEW] `netlify/functions/lead.ts`
Implementación de la función serverless para recibir peticiones del cliente:
- Validación rigurosa con `zod` del payload (canal, seccion_origen, servicio_interes, pagina, timestamp, honeypot).
- Verificación del honeypot (si viene lleno, ignorar silenciosamente).
- Reenvío al webhook de n8n usando `N8N_WEBHOOK_URL` desde `process.env`.
- Timeout (5s) y un reintento en caso de fallo, respondiendo `202 Accepted` al cliente sin bloquear.
- Logging estructurado en el servidor.
- CORS para restringir orígenes y rate-limiting básico verificando la IP en los headers.

### 3. Sistema de Diseño y Estilos

- Configurar colores principales: Azul profundo (#0A2540), Cian eléctrico (#00C9FF), Blanco sólido (#FFFFFF) y Gris claro (#F5F5F5).
- Fuentes: Sans-serif moderna (ej. Inter o Poppins vía Fontsource).

### 4. Componentes Frontend (Astro Islands)

#### [NEW] `src/data/content.ts`
Archivo central para todo el copy, servicios, enlaces y datos de contacto, permitiendo fácil edición sin tocar la UI.

#### [NEW] `src/components/ContactButtons.tsx` (o `.astro` con script de cliente)
Isla de Astro (`client:load`) manejando:
- Interfaz de los botones "Contactar por WhatsApp" y "Enviar Correo".
- Campo honeypot oculto.
- Lógica de *debounce* (5 segundos usando `sessionStorage`).
- Fetch asíncrono no bloqueante a `/api/lead`.
- Redirección inmediata a `wa.me` o `mailto:`.

#### [NEW] `src/components/`
Creación de las secciones de la Landing Page como componentes estáticos:
- `Header.astro`
- `Hero.astro`
- `ProblemSection.astro`
- `ServicesGrid.astro`
- `PositioningSection.astro`
- `ProcessSteps.astro`
- `TrustSection.astro`
- `FinalCta.astro`
- `Footer.astro`

#### [NEW] `src/pages/index.astro` y `src/layouts/BaseLayout.astro`
Ensamblaje final de la página con SEO técnico, Meta Tags, Open Graph, y estructura semántica (WCAG AA).

## Verification Plan

### Automated Tests & Linting
- Se ejecutará `npm run lint` para asegurar la calidad de código (TypeScript, Prettier, ESLint).
- Se ejecutará `npm run build` para garantizar que la compilación de Astro con Netlify SSR funciona correctamente y que ninguna variable privada se filtra al bundle público.

### Manual Verification
- Levantar servidor de desarrollo en local (`netlify dev`).
- Probar que los envíos del formulario pasen por el debounce, verifiquen el honeypot y realicen el POST a `http://localhost:8888/api/lead`.
- Inspeccionar la consola del navegador para verificar que el webhook de n8n nunca es expuesto.
- Verificar Lighthouse score localmente usando Chrome DevTools para garantizar el objetivo de >95 en todas las métricas.
